# DataSentinel
A Sensitive Data Protection and Loss Prevention Framework for Enterprise Communication Platforms 

# Abstract
As the use of Artificial Intelligence (AI) chatbots and online communication platforms continues to grow, the risk of exposing sensitive company information has also increased. Employees may accidentally or intentionally share confidential files, documents, or business data through email or AI chat applications. This can lead to data leakage, financial loss, and security risks for organizations. This project proposes a chat filtering system that helps protect sensitive company information before sharing. The system identifies confidential files, folders, and text based on predefined rules and security policies. When a user attempts to send sensitive information through email or an AI chatbot, the system analyzes the content and blocks or warns the user if confidential data is detected. The solution aims to reduce accidental data leakage while allowing normal communication to continue without interruption. It is designed to be simple, efficient, and easy to integrate into a company’s existing workflow, helping improve data protection and cybersecurity.
